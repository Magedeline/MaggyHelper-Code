# Desolo Zantas Wiki Home

Welcome to the **Desolo Zantas / MaggyHelper** project wiki.

This project is a large Celeste campaign and code mod built around custom chapters, bosses, character systems, cutscenes, assets, and editor integrations. The wiki exists to give contributors and playtesters a stable place to find project structure, workflow rules, and feature-specific guidance without digging through long source files or PR history.

## What This Repository Contains

- A 21-chapter main campaign with additional B, C, D, and DX-side content
- Custom gameplay systems, boss fights, and progression logic
- Kirby player support with custom movement and ability mechanics
- Loenn entity definitions and mapping-side integrations
- Large dialog, portrait, sprite, and audio content pipelines
